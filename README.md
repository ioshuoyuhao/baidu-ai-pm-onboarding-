## 协作方式

本仓库由本人主导，配合 AI 助理（Kimi Work）协同完成：任务取舍、结论判断、术语卡口述与改写等核心判断由本人完成；资料检索、文档结构化沉淀、代码实现由 AI 助理执行，本人逐模块审批后入库。每个模块对应独立 commit，过程可追溯。
