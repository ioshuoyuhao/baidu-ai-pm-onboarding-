### 今日反思

今天最大的感受是 AI 工具用起来并没有想象中那么省事。检索和填表确实快了，但省下来的时间基本花在了核对上：确认每条信息来源是否真实、官网链接是否有效，查不到的还要判断是"没有"还是"没公开"。另外新接触一个领域时，信息源的筛选、产品的实际体验、行业社区的评价，这些功夫一样省不掉。

我的理解是，这不是 AI 不好用，而是分工本来就该如此：检索、整理这类工作可以交给 AI，但前提是事先把验收标准定清楚（这次要求每格都附证据链接），核对成本才可控；结论和取舍必须自己拍板；产品体验和行业积累没人能替，只能自己花时间。总结下来，AI 对我最大的价值不是替我省事，而是逼我把"做到什么程度算合格"提前想清楚。
